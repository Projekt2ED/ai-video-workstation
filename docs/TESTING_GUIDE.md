# 测试与验收标准

## 一、通用验收

每次代码修改后必须完成：

- [ ] 项目能正常启动：`npm run dev`
- [ ] 项目能正常构建：`npm run build`
- [ ] 类型检查通过：`npm run lint`（tsc --noEmit）
- [ ] 前端页面可正常访问：http://127.0.0.1:3000
- [ ] 浏览器控制台无明显报错
- [ ] 不影响已有核心功能

## 三、集成验收

### 3.1 A功能完整流程

```
1. 进入看板首页
2. 点击"TK视频仿写"进入 Step1
3. 输入 TK 链接，提取逐字稿
4. 点击"下一步"进入 Step2
5. 填写产品信息，选择风格
6. 点击仿写，生成脚本
7. 点击"确认"进入 Step3
8. 选择素材，点击合成
9. 合成完成后保存到看板
10. 在看板首页查看任务
11. 在任务历史查看已完成任务
```

### 3.2 B功能完整流程

```
1. 进入看板首页
2. 点击"中文转英文"进入 B 功能
3. 选择预设案例或上传视频
4. 选择配音音色
5. 点击翻译
6. 翻译完成后保存到看板
7. 在看板首页查看任务
8. 在任务历史查看已完成任务
```
